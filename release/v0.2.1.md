## discord-agent-hub v0.2.1

Generated-file and code-execution usability release.

### Highlights

- Added downloadable generated files from provider-side code execution:
  - OpenAI Code Interpreter container files
  - Claude Files API outputs
  - Gemini inline code-execution outputs such as generated plots
- Added downloadable fenced code blocks:
  - `latex` / `tex` blocks are attached as `.tex`
  - `python` / `py` blocks are attached as `.py`
- Added `/knowledge-show` to inspect imported knowledge sources and their registered documents
- Added `query` filtering to `/agent-list` for servers with many agents
- Added runtime font-file support for provider-side code execution:
  - OpenAI: `.ttf`, `.otf`, and `.ttc` attachments are uploaded to the Code Interpreter container
  - Claude: `.ttf`, `.otf`, and `.ttc` attachments are uploaded as `container_upload`
- Claude image attachments are also uploaded to the code execution container when code execution is enabled

### Fixes

- Empty Discord messages are ignored instead of being saved into history and resent to providers
- Gemini now avoids sending `google_search` together with `code_execution`, preventing provider errors for code-execution agents that also declare web search
- Code-execution prompts now include a short provider-side capability note so agents are less likely to deny that code execution is available
- Claude uploaded-file instructions now explicitly tell the model to search the container before saying a file is unavailable

### Documentation

- Clarified provider-native knowledge backend recommendations:
  - OpenAI agents should prefer `openai_file_search`
  - Gemini agents should prefer `gemini_file_search`
  - Claude agents should use `hub_lexical` for now
- Documented generated-file behavior and provider-specific input-file handling
- Documented observed Japanese fonts in provider-side code execution environments

### Notes

- Generated file attachments are capped to keep Discord uploads bounded.
- Runtime font files are provider-side execution inputs, not general knowledge-source documents.
- Provider execution environments are managed by each provider and may change; agents should discover available fonts at runtime before rendering Japanese plots.
